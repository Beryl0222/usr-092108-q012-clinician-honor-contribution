# 医者荣誉贡献档案

全国性医者致敬项目（个人通道 + 团队通道）的领域资料、事件契约与最小可运行模型。
把执业资质、任职时间、项目角色、同行证明、公益记录、奖项类别、推荐意见、患者同意、
媒体许可和公开版本组织成**可核验关系**，并支持署名遗漏后的逐渠道更正。

## 目录

- `contracts/domain.schema.json`：26 类领域事件的信封与按事件类型的载荷契约（JSON Schema 2020-12）。
- `contracts/invariants.md`：领域不变量的权威中文表述（时间窗、不继承、按用途授权、最小核验等）。
- `src/catalog.js`：事件类型、聚合类型与全部枚举的单一事实源。
- `src/validator.js`：写入边界的结构校验（必填、枚举、日期、时间窗倒置、禁止字段、重复事件）。
- `src/archive.js`：追加式事件重放、投影与不变量引擎，以及业务查询。
- `data/sample.json`：端到端中文样例事件流（见下）。
- `scripts/impact-report.mjs`：从样例生成“推荐医院即时影响面”报告。
- `tests/`：契约、领域不变量（含反例）、schema 一致性共 28 项。

## 核心规则（摘要）

1. **事件只追加**：纠错产生后继 `ATTRIBUTION_CORRECTED`，原署名与真实分工永不被改写。
2. **团队成果 = 时间段 × 实际参与者**：离职、退休、跨院合作保留窗内原贡献；
   后来成员不能继承自己未参与的事项，更正补登也受时间窗约束。
3. **不按病例数自动评断医德/医术**：评分、排名、完整病历字段在写入边界即被拒绝。
4. **患者授权按用途独立**：评审 / 盛典 / 长期宣传可分别授予与撤回；撤回后立即给出
   受影响的在播渠道。
5. **公开版本双端核对**：医院与候选人对同一版本共同核对后才能发布；渠道发布还需
   当时有效的患者授权与媒体许可。
6. **错署名逐渠道同步**：更正后即时返回受影响的榜单页、患者故事、媒体材料及其
   `pending/synced/failed` 状态。
7. **外部核验最小化**：只回应白名单事实（资质、任职/参与时间窗、奖项、公益存在性），
   证据包显式不含完整病历，超额披露会被标记。
8. **身份归并**：姓名异体、机构更名、重复推荐、材料补正都归到同一规范候选。

## 样例事件流讲了什么

`data/sample.json` 是一条可直接重放的完整故事：

- 医院 2021 年更名；林慧文与“林惠文”异体档案归并；旧机构名下重复团队档案归并。
- 陈守业（2022 退休）、周景明（2020 离职）、苏方远（仁和医院跨院，2014—2018 实际参与）、
  赵一鸣（2021 才加入）各有独立时间窗。
- 公益巡诊（公益 + 多机构）、胸痛中心（临床 + 专科建设）两类贡献与同行证明；
  个人、团队两条推荐通道与重复推荐归并、材料补正。
- 团队荣誉发布时遗漏苏方远 → `ATTRIBUTION_CORRECTED` 后继更正 → 榜单页 / 患者故事 /
  媒体材料 / 盛典归档四渠道逐一同步。
- 患者之后撤回“长期宣传”用途（评审、盛典不受影响）→ 三渠道旧版下架、媒体许可撤销 →
  出不含患者叙事、带正确署名的新版，双端核对后重新发布。
- 主办方抽查：医院只出具四项白名单事实的最小证据包，明确不含完整病历。

## 本地检查

```bash
node --test          # 全部 28 项测试
node scripts/impact-report.mjs   # 打印样例的更正/撤回影响面与核验视图
```

## 在代码中使用

```js
import { validateEventStream } from "./src/validator.js";
import { replay } from "./src/archive.js";

const errors = validateEventStream(events);       // 写入边界
const archive = replay(events);                   // 重放投影
archive.violations;                               // 领域不变量问题（照实载入并标出）
archive.channelsAffectedByCorrection("corr-..."); // 推荐医院即时影响面
archive.channelsAffectedByConsentWithdrawal("consent-...");
archive.effectiveAttribution("award", "award-...");
archive.nomineeView("p-...");                     // 身份归并后的候选汇总
archive.verificationView("vp-...");               // 最小核验视图
```

## 领域边界

事件标识、发生时间与版本不可原地修改，业务更正一律产生后继记录。涉及个人、机构或
商业敏感信息时，调用方只读取完成职责所必需的字段；主办方核验不接触完整病历。
